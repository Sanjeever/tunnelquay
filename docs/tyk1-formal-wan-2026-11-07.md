# tyk1 正式实现公网验收

2026-11-07 北京时间 13:00:24–13:07:47 完成准备、运行与清理，随后汇总证据。源码提交为 `a0e5450`，服务端 Linux amd64、客户端 macOS arm64 均从当前源码构建，注入该提交号，版本为 `dev`。服务端版本 API 和客户端版本命令均核对提交号。这是正式实现的验证，不是签名 Release 发布。

## 部署与测试路径

服务端为 tyk1（139.180.203.137），Ubuntu 22.04、1 核、约 951 MiB 内存。独立目录为 `/opt/tunnelquay-formal-wan-20261107-050024`，使用新数据库与身份；临时 systemd 单元设运行期限、256 MiB 内存上限，不设开机启动。首次上传 SSH 认证握手超时，重连上传并核对程序就绪后开始验收。

本机同时运行当前 QUIC 客户端、TCP 客户端及一份保留的旧客户端二进制，各用独立身份目录。新端上报 `udp-stream-v1`，旧端不含该能力。目标服务绑定 macOS 回环地址。临时放行本机 UFW 的 TCP/UDP 7000 和 UDP 27000–27009；原有规则保留，结束删除新增规则。

两条数据路径分别记录。

- 接入段测试：tyk1 本机 UDP 请求 → 本机业务监听 → 跨公网 QUIC/TCP 接入 → macOS 回环目标 → 原路返回。用于验证接入承载，不包含公网业务 UDP 的额外往返。
- 公网业务测试：macOS 请求 → tyk1 公网业务端口 → 接入链路 → macOS 回环目标 → 原路返回。该路径仍含原生公网 UDP。

同一 QUIC 客户端同时配置默认 DATAGRAM、可靠流和组合协议隧道，另有 TCP 接入可靠隧道及旧客户端 DATAGRAM 隧道。组合协议配置创建成功；本轮数据负载为 UDP，没有增加 TCP 大文件验证。

## 数据结果与延迟

单来源每档二十个报文，间隔 100 毫秒，携带路径标记与序号并完整校验内容；收全即结束，否则最后一次发送后再等待二十秒。两种接入的接入段可靠测试结果如下。

| UDP 负载 | TCP 接入正确回包 | QUIC 可靠流正确回包 |
| --- | --- | --- |
| 900 字节 | 20/20 | 20/20 |
| 1200 字节 | 20/20 | 20/20 |
| 8192 字节 | 20/20 | 20/20 |

同一 QUIC 接入再运行三个独立来源，各发二十个 8192 字节报文，合计 60/60，未发现串包、内容错误或重复回包。单来源 QUIC 8192 字节 RTT p50 约 3092 毫秒，p95 约 6310 毫秒；三个来源并发时 p95 分别约 14.31、13.83、15.28 秒，最大约 15.45 秒。分位数采用成功样本的最近秩算法，包含来源会话首包建立成本。

公网业务路径另测 900 字节，默认 DATAGRAM 为 13/20，可靠流为 16/20，收到的报文均正确。可靠流不能将含公网业务 UDP 的整条路径变为可靠交付，本轮没有进一步定位这些缺失报文所在方向。

公网业务与接入段负载存在重叠，两种接入顺序执行。上述小样本用于功能与延迟观察，不构成协议性能对比、长期丢包率或容量结论。秒级尾延迟仍需业务自行评估。

## 配置、兼容与恢复

管理编排共记录二十八项检查，全部通过，包含以下实际行为。

- 公网版本、首次登录改密与配置保存成功；真实 Chromium 登录公网管理端，可靠流选择值、期望/生效配置均正确，页面操作期间未捕获脚本异常。
- 将可靠流改为 DATAGRAM 并修改目标，新来源取得新目标回包，原来源继续原目标；再改回可靠流并迁移公网端口，原端口的已有来源继续正确回包，新端口可用。
- 旧客户端的 DATAGRAM 配置可运行。尝试改为可靠流时明确返回缺少 `udp-stream-v1`，保留原生效 DATAGRAM，旧端实际回包继续成功。
- 用真实 UDP 监听占用 27007，组合协议更新明确失败，原 27003 生效配置继续转发；随后停用，旧公网端口及新端口的各代来源均无法继续取得对应新请求回包。
- 停用后停止 QUIC 客户端，离线修改目标及承载，再用原身份重连，停用状态保留；重新启用后新目标转发成功。日志没有观察到主动停启之外的接入重连。
- 所有隧道停用后，当前业务连接为零，查询返回十六条历史，保留两个实际目标与配置代次 1、2、3、7 的快照。

控制检查报文允许最多三次有编号取样，以免把 UDP 偶发丢失混同于配置行为；本轮目标确认均在第一次取样取得正确回包。该检查不替代上表中的原始收发统计。

远端 `remote-evidence.tar.gz` 保存接入段原始收发记录、并发结果、资源采样与脱敏服务端日志；`local-evidence.tar.gz` 保存编排源码、目标与客户端日志、配置检查、历史快照和浏览器记录。本机副本位于 `/tmp/tunnelquay-formal-wan.BMuLn9`。
