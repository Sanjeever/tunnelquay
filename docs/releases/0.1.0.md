# TunnelQuay 0.1.0

首版提供独立服务端和客户端。服务端内嵌中文管理界面，集中保存设备、隧道配置、连接记录和升级任务；客户端保持无状态并按服务端拨号原语转发流量。

- 采用 TLS 1.3 + Yamux 的加密 TCP 多路复用接入，统一承载控制信令、TCP 与 UDP 业务转发及升级文件流。
- 支持 TCP、UDP、TCP + UDP 隧道，手动或自动分配固定公网端口。
- 隧道配置由服务端直接管理，失败保留原配置；修改目标保留已有连接，停用和删除关闭关联连接。
- 提供 Ed25519 设备独立密钥认证、身份撤销、自动重连、实际链路 RTT、连接统计与保留 7 天的分页历史。
- 首次登录强制修改临时密码，管理密码与客户端接入凭据分别管理。
- 支持验证官方签名包、替换客户端程序后退出，由外部守护或人工重启；实际版本重新上线后确认升级结果。
- 提供 Linux、macOS、Windows 的 amd64、arm64 构建、归档、校验文件及签名发行清单。

客户端和服务端均以前台方式运行。Web HTTPS 与域名由用户自行配置反向代理。远程升级需要正式发行公钥，配置步骤见 [开发与部署](../development.md#版本与发行)；平台原生验证与发布待办见 [验收记录](../verification.md)。
