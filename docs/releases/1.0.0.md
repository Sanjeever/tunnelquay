# TunnelQuay 1.0.0

首个稳定版。在 0.99.0 的基础上更新管理界面与品牌，补齐服务端常驻管理、接入加固与日常运维能力。

- 新增项目图标与深浅主题（含跟随系统），统一全局动效、复制与加载反馈，并支持减弱动态效果偏好。
- 隧道与连接详情改用右侧抽屉；删除、撤销、重置凭据与发起升级改用应用内确认弹窗，替代浏览器原生对话框。
- 服务端新增 `-service install/uninstall`，支持 Linux `systemd`、macOS `launchd` 与 Windows 计划任务。
- 接入设备弹窗增加 Windows PowerShell 一键下载并接入命令。
- 设备页显示服务端版本，低于服务端版本的在线设备提供“可升级”入口，直达客户端升级面板。
- 当前连接支持在列表与详情中手动断开，断开记录写入历史。
- 客户端升级面板可查看已缓存的发行包版本并清理；有进行中升级任务引用的版本拒绝清理。
- 接入握手严格校验 ALPN `tunnelquay/1`，公网 HTTPS 扫描不再进入复用会话并产生告警日志。
- 管理登录限流改为按客户端 IP 统计，成功登录清除该来源计数，单个来源的失败尝试不会锁定管理员。

Web HTTPS 与域名由用户自行配置反向代理。远程升级需要正式发行公钥，配置步骤见 [开发与部署](../development.md#版本与发行)；平台原生验证与发布待办见 [验收记录](../verification.md)。
