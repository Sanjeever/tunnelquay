## 架构简化与无状态客户端重构验收（2026-11-07）

正式发版前完成核心架构收敛：
1. 传输层统一为 TLS 1.3 + Yamux 的 TCP 多路复用连接，移除 QUIC 依赖（`github.com/quic-go/quic-go`）、UDP 分片重组缓存及按隧道切换承载模式（`udp_mode`）。
2. 数据库版本与通信协议版本统一归零为 `1`，移除未发布阶段的旧设备身份迁移接口、存储迁移及界面入口。
3. 剥离客户端保存的隧道配置状态、配置代次（`revision`）与 `prepare`/`snapshot`/`stop` 同步流程。客户端收敛为无状态连接器与拨号执行器（`dial` 原语），隧道状态统一由服务端管理。
4. 完善客户端 CLI 与管理端闭环：支持单一接入串（`-connect 'tq://<credential>@<host>:<port>'`）、环境变量（`TUNNELQUAY_CONNECT` / `TUNNELQUAY_CREDENTIAL`）、系统常驻服务管理（`-service install/uninstall`）与服务端 `-reset-password` 管理密码重置；支持服务端分发已验证客户端程序与一键安装脚本、接入地址自动推导填充、离线/已撤销设备删除与关联隧道清理、共享登记凭据重置、设备上线与保存时自动探测目标连通性（`POST /api/tunnels/{id}/probe`）、隧道克隆与常用服务快捷预设、反向代理客户端 IP 识别以及按隧道配置来源 IP / CIDR 白名单过滤（`allow_cidrs`）。

验证环境与结果：
- **macOS arm64（Go 1.26.0）**：执行 `go test ./... -count=1`、`go vet ./...`、`pnpm --dir web build` 与 `pnpm --dir web exec playwright test --headed` 全部通过。覆盖 Ed25519 设备密钥认证、拒绝冒领与重放、身份撤销、离线/已撤销设备删除、共享登记凭据重置（新设备旧凭据被拒、已绑定设备不受影响）、管理密码重置（旧会话与旧密码失效、新临时密码强制改密）、单一接入连接串解析与格式化、跨平台常驻服务安装与卸载（`systemd` / `launchd` / `schtasks`）、服务端客户端程序分发与一键安装脚本、TCP 双向流与半关闭、UDP 多来源 8192 字节回包、配置切换与端口冲突保留原配置、设备上线自动探测与手动目标探测、反向代理客户端 IP 识别、来源 IP / CIDR 白名单放行与拦截、未知控制请求返回 `unsupported_message`、代表性负载、一键升级自动拉取官方发行包及单进程升级实际文件替换与重启版本确认，以及真实 Chromium 桌面与 390px 窄屏界面验收。
- **Linux amd64（tyk1，139.180.203.137）**：交叉编译 `client.test` 与 `server.test` 上传至隔离目录原生执行通过，包含三个来源的 8192 字节与 65507 字节最大 UDP 数据报回包验证，测试结束后清理全部临时文件与监听。

## 代表性负载

`TestRepresentativeLoad` 在同一测试进程中运行服务端、5 个客户端、20 条 TCP 隧道与 20 路并发连接，单连接发送约 4 MiB 并接收等量回包，合计约 160 MiB，随后执行 100 次新连接首字节延迟采样，并验证删除隧道后活动连接与 goroutine 回收至基线范围。资源上限与队列策略见 [设计文档](design.md#资源边界)。
